# 项目定位与已有工作

2026-10-07检索GitHub的颜文字、自动插入、情绪与情景回应相关词，找到了以下相近项目：

- [kaomoji-collection](https://github.com/kaomojiya-collection/kaomoji-collection)：分类颜文字数据，本项目已经使用它。
- [splatmoji](https://github.com/cspeterson/splatmoji)：桌面表情与颜文字搜索、选择和输入工具。
- [kaomoji_mcp_server](https://github.com/frankunderwood-w/kaomoji_mcp_server)：向AI代理提供颜文字能力，涉及思考、庆祝、道歉等场景。
- [ai-sticker-pack](https://github.com/Lumenocturne/ai-sticker-pack)：聊天机器人根据场景选择表情包，输出媒介为图片。

这次检索没有确认一个与当前全部流程、中文取向和独立CLI定位完全相同的现成项目。但有限关键词检索不能证明不存在，也不能证明原创性或首创。

当前定位：面向中文情景，把“生成回应”和“加入可追溯来源的颜文字”拆开，提供普通版本、点缀版本与操作记录。重点是回应身份、情绪适配、插入位置和可控密度，而不是生成随机颜文字或仿写某位作者。

下一步可以收集用户对真实情景回应的选择与修改，评估得体性、事实新增、表情位置与表达自然度。优先改进有具体失败案例的部分，再决定是否更换更大的中文模型。
