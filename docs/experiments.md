# 实验结论

早期测试TinyStyler官方配置，直接中文输入大量变为未知token，没有得到可用中文仿写；结论仅针对所测配置。当前选择中文模型生成正文，规则做表达点缀。

Qwen3-1.7B Q8_0可以生成中文，但曾混淆角色、编造拒绝理由和未见图片细节。程序用少量记录明确的规则修正已知问题，不将修正算作模型能力。每次运行保留原始响应。

开发案例包括感谢、祝福、邀约、安慰、通知、尺寸与投诉。这些经过观察和修改，属于开发验证，不是独立盲测。没有可靠的风格相似度或全面生成质量指标。

当前每段至少一个颜文字，信息不足也可以微笑回应，补充建议单独展示。历史上“不加表情”与“原味完全无点缀”的规则已废止。

相近项目和有限检索见 [related_projects.md](related_projects.md)。不宣称首创。后续应分别收集回应贴切性、建议必要性和表情位置的反馈。
