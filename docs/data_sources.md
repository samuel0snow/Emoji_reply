# 小词库来源

`style_bank.json` 中的 `original` 表示早期人工从少量表达中选出的短词和表情，例如“瓦”“滴”“介个”。发布目录不包含原始图片、完整原文或个人聊天；这些条目是固定候选，不是作者识别或风格训练语料。

`cute_variants`、`kankan` 和 `faces` 标记保留各自参考网页链接；这些来源用于扩展候选，不能证明某位作者使用过这些表达。

`kaomoji_collection` 是授权颜文字候选。完整上游库不随项目分发，仅保留小型候选、筛选元数据与MIT版权声明。支持表情 `(｡´･ω･)ﾉﾞ` 来自上游yoshiyoshi类别，中性表情 `(・_・)` 在程序中作为固定兜底。
